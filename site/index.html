Made for reading the feed

It shows the x.com website you already use, inside a Mac window that refreshes the feed every minute, except while you're scrolled down, writing a post, or watching a video.

Refreshes, then waits

Refreshes Home every minute, or every 2, 5 or 10. It holds off while you're scrolled down, typing a post, watching a video, or using a menu, and uses X's own "Show posts" button when there is one.

Following shows Recent

Picks Recent each time Following opens, so you see the latest posts first. You can turn this off in the View menu.

Keeps your place

If a refresh happens while you're scrolled down, the post you were reading comes back, marked "You were here".

Pull to refresh

At the top of the feed, pull down with a trackpad or keep scrolling a mouse wheel to refresh right away.

Standard Mac controls

Settings, Back, Forward, Home, Stop, find on page, text size, keep on top, open at login, and a Dock badge and notifications for unread counts.

Protects your drafts

Asks before a reload, a link, Back, or Quit would discard a post you haven't sent.

Pinned lists too

A list or community pinned on Home refreshes the same way as For you and Following.

Opens your X links

Drop an x.com link on the Dock icon, or use Services › Open in X for macOS from another app.

Collects nothing

No account of its own, no telemetry, and no saved posts. Links to other sites open in your browser.

Keyboard shortcuts

Every toolbar button has a keyboard shortcut, and so does each feed and Settings.

Details

Requires

macOS 27 or later, on a Mac with Apple silicon.

Install

Unzip it, move X to Applications, and open it. Sign in to X in the window.

Updates

Checks this site once a day and asks before installing. X › Check for Updates… checks now.

Signed

Signed with Developer ID and notarized by Apple.

Privacy

No telemetry and no account of its own. The only request the app makes itself is the daily update check, and notifications say only how many are unread.

Source

The code is on GitHub at github.com/banastas/X, where you can also report a problem.

X for macOS is an independent app. It is not made, endorsed, or supported by X Corp. It shows the x.com website, you sign in to X yourself, and X's rules and data practices apply to what you do there.
